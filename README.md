# 🐝 HORNET SYNTH

Интерактивный браузерный FM-синтезатор звука полёта шершня с симуляцией эффекта Доплера, стереопанорамированием и встроенными аудиоэффектами. Работает на базе **HTML5 Canvas** и **Web Audio API**.

🔗 **[Запустить онлайн (GitHub Pages)](https://github.io<название-репозитория>/)**

---

## ✨ Возможности
* **FM-синтез в реальном времени**: генерация жужжащего тембра с нелинейным формированием волны и модуляцией шума.
* **Пространственный радар и эффект Доплера**: траектория полёта шершня автоматически изменяет стереопанораму (левый/правый канал), громкость и сдвиг частоты при приближении и удалении.
* **Ручное управление полётом**: удерживайте левую кнопку мыши (или палец на сенсорном экране) внутри кругового радара, чтобы управлять траекторией вручную.
* **Встроенные эффекты**: стерео-хорус (`Chorus`), пинг-понг дилей (`Delay`) и реверберация (`Reverb`).
* **Режим ХАОС**: автоматическая плавная модуляция всех пяти параметров синтеза.

## 🎛 Управление и горячие клавиши

### Регуляторы (крутилки)
Управляются перетаскиванием мыши вверх/вниз, колёсиком мыши или клавишами:

| Параметр | Клавиши | Описание |
| :--- | :---: | :--- |
| **TONE** | `Q` / `A` | Базовая частота основного тона (от 50 Гц до 1000 Гц) |
| **NOISE** | `W` / `S` | Глубина FM-модуляции и уровень шума крыльев |
| **AGIL** | `E` / `D` | Манёвренность — высокочастотные колебания и треск |
| **SPEED** | `R` / `F` | Скорость вращения шершня по орбите |
| **RAD** | `T` / `G` | Радиус полёта (влияет на силу эффекта Доплера и панораму) |

### Эффекты и режимы

| Действие | Клавиша | Описание |
| :--- | :---: | :--- |
| **1: CHORUS** | `1` | Включить / выключить стерео-хорус |
| **2: DELAY** | `2` | Включить / выключить стерео-дилей |
| **3: REVERB** | `3` | Включить / выключить реверберацию |
| **ХАОС** | `X` | Автоматическая модуляция всех параметров |
| **РАНДОМ** | `Z` | Случайная генерация настроек звука |
| **СБРОС** | `C` | Сбросить все регуляторы и эффекты в ноль |
| **ЗВУК: ВКЛ/ВЫКЛ** | `Пробел` | Включить или отключить вывод звука |
